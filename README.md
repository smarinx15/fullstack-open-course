# Full Stack Open Course

This repository contains my solutions and exercises for the [Full Stack Open](https://fullstackopen.com/) course by the University of Helsinki.

## 📚 Course Description

Full Stack Open is a deep dive into modern web development with JavaScript. The main focus is on building single page applications with ReactJS that use REST APIs built with Node.js. The course covers:

- React
- Redux
- Node.js
- MongoDB
- GraphQL
- TypeScript
